Fairspec ships with a software ecosystem so you can adopt the standard from your language of choice, your AI assistant, or a desktop UI.

:::card{title="Python" icon="file-code" href="/python/getting-started/"}
Validate, infer, and query Fairspec descriptors from Python. Built on top of the data ecosystem with first-class support for pandas and Polars DataFrames.
:::

:::card{title="TypeScript" icon="braces" href="/typescript/getting-started/"}
A fast TypeScript framework with the same API surface as the Python package. Ships an opinionated terminal CLI and adapters for tabular and JSON formats.
:::

:::card{title="Rust" icon="cog" href="/rust/getting-started/"}
A single prebuilt `fairspec` binary carrying the terminal CLI and the MCP server, plus a library of crates built on Polars. No runtime to install.
:::

:::card{title="CLI Tool" icon="square-terminal" href="/cli-tool/"}
The `fairspec` command, shipped by the Python, TypeScript and Rust packages. Validate datasets, infer schemas, and query tables from scripts, CI pipelines, or an interactive terminal.
:::

:::card{title="MCP Server" icon="sparkles" href="/mcp-server/"}
Connects AI assistants to the Fairspec framework over the Model Context Protocol. Lets your editor or chat validate datasets, infer schemas, and query tables in plain language.
:::

:::card{title="Desktop" icon="layout-dashboard" href="/desktop/"}
A desktop application for validating and inferring descriptors through a visual interface. Available for macOS, Windows, and Linux; your files never leave your machine.
:::
